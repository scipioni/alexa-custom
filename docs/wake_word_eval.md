# Wake-Word Detection Evaluation

The `alexa-wake-eval` tool scores stage-1 wake detection offline — no microphone, no parec — and reports **false-positives-per-hour** and **miss-rate** for a given configuration.

## Quick start

```bash
# Generate corpus from Piper TTS (one-time, ~30 s)
alexa-wake-eval --gen-corpus

# Score with default config (vosk, conf=0.65, mode=first, rms=0.02)
alexa-wake-eval

# Score with verbose per-clip output
alexa-wake-eval -v

# Sweep backends, thresholds, and confidence modes
alexa-wake-eval --sweep

# Save regression baseline
alexa-wake-eval --save-baseline eval/baseline.yaml

# Check against baseline (exits non-zero on regression)
alexa-wake-eval --check-baseline eval/baseline.yaml
```

## Corpus

Located at `eval/corpus/` (gitignored by default — regenerate from Piper on each machine).

```
eval/corpus/
    positive/     clips that SHOULD trigger a wake
    negative/     clips that must NOT trigger a wake
    manifest.yaml provenance metadata (used by the harness)
```

The corpus is generated by `--gen-corpus` using the Piper voice at
`models/piper/it_IT-paola-medium.onnx`.  Each text is synthesised at 0 dB
and then three attenuated copies (−6, −12, −18 dB) are created to emulate
far-field / quiet cross-talk.

**Positive texts** (must wake): `"ehi galileo"`, `"assistente"`.

**Negative texts** (must not wake): deliberate near-misses (`"gabriele"`,
`"galleria"`, `"assistenza"`) plus common Italian phrases.

### Ambient/real-speech clips (not yet in corpus)

The TTS-only corpus is clean and may **understate** real-world false-positive
rates — real room conversation is harder.  To add recorded clips:

1. Place 16 kHz mono WAV files into `eval/corpus/negative/` (or `positive/`).
2. Add entries to `eval/corpus/manifest.yaml` manually or extend
   `generate_corpus()` in `alexa_custom/wake_eval.py` with a download step.
3. Storage options for recorded fixtures:
   - **Small clips (< 500 kB total)**: commit directly to the repo.
   - **Large sets**: use Git LFS or a `--download-ambient` step in `alexa-setup`.

Italian Common Voice clips (`cv-corpus-*/it/clips/*.mp3`) can be converted
with `ffmpeg -i clip.mp3 -ar 16000 -ac 1 clip.wav` and are a good source of
natural negative speech.

## Metrics

| Metric | Definition |
|--------|-----------|
| **FP/hour** | false wakes ÷ total negative audio duration in hours |
| **Miss rate** | missed positives ÷ total positive clips |

FP/hour is duration-normalised so corpora of different sizes are comparable.
A value of ~42 FP/hour over 85 s of negative audio means 1 false wake in the
test set; once real ambient clips are added the number will be more meaningful.

## Configuration options

| Flag | Description | Default |
|------|-------------|---------|
| `--confidence` | Vosk acceptance threshold (grammar mode only) | 0.65 |
| `--confidence-mode` | `first` / `min` / `mean` (grammar mode only) | `first` |
| `--rms-threshold` | Energy pre-gate threshold | 0.02 |
| `--vosk-model` | Path to Vosk model directory | `models/it` |
| `--wake-words` | Space-separated wake word phrases | `"ehi galileo" assistente` |

### Vocabulary mode and the eval harness

The harness scores clips against the same Vosk recognizer configuration used
at runtime.  The `vosk_grammar` setting (default: `false`) affects how results
are interpreted:

- **`vosk_grammar: false` (free-vocabulary, default)**: Vosk decodes freely;
  the harness uses `_approx_wake_match` (fuzzy word-overlap) to check whether
  the transcript contains the wake phrase.  This is the live-session path and
  the most representative eval mode.
- **`vosk_grammar: true` (grammar mode)**: Vosk is restricted to the wake-word
  vocabulary; the harness uses exact alias-map lookup and confidence gating.
  Confidence and confidence-mode flags only have effect in this mode.

### Sweep findings (TTS corpus)

The `--sweep` output showed that **the RMS gate (≥ 0.01) is the dominant fix**
on TTS data, reducing FP count from 5-10 (with no gate) to 1.  The remaining
FP ("assistenza" at −18 dB) escapes via `FinalResult` (no endpoint fires on
the very quiet clip), which uses `rms_threshold=0.0`.

**Confidence mode** has no visible effect on clean TTS (Vosk returns conf=1.0
for all tokens) and is irrelevant in free-vocabulary mode.  Its value will be
measurable in grammar mode once real ambient/room recordings are added to the
negative corpus — that is where partial/noisy decodes produce mixed per-token
confidences.

## Regression guard

Once a satisfactory config is found:

```bash
alexa-wake-eval --save-baseline eval/baseline.yaml
```

Future runs can check against it:

```bash
alexa-wake-eval --check-baseline eval/baseline.yaml
# exits 1 if FP/hour or miss-rate has regressed beyond tolerance
```

The tolerance is +20% + 0.1 on FP/hour and +5 pp on miss-rate (see
`check_baseline()` in `alexa_custom/wake_eval.py`).
