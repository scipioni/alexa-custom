🔍 Scansione rete (manuale)
La scansione automatica è disattivata: le telecamere provengono dal blocco cameras di settings.yaml. Questa subnet è usata solo dal pulsante manuale "🔍 Rescan subnet" nella dashboard.
Notazione CIDR. Esempi: 192.168.1.0/24 (254 host)  ·  10.0.0.0/16 (65534 host)
🔑 Password (telecamere / scan / accesso)
Le password non si impostano più da qui: vivono nel file .env (git-ignored) accanto a docker-compose.yml.
  • CAMERA_USER / CAMERA_PASSWORD — credenziale comune delle telecamere
  • SCAN_USER / SCAN_PASSWORD — credenziale dello scan manuale (default: quella delle telecamere)
  • GUI_PASSWORD — password di accesso a questa interfaccia
Per cambiarle: modifica .env e riavvia il servizio. Vedi .env.example.
